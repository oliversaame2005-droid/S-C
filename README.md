# FORM — Athlete Performance

A responsive first concept for a strength and conditioning coaching brand. FORM and the coach name are placeholders.

## Run

Use Node.js 18 or newer. No dependencies need installing.

```sh
npm run dev
```

The server listens on port 3000, or `PORT` if provided. Run `npm run check` for JavaScript syntax validation.

## Included

Home, programs, about, shop, and contact views; program/category filters; a persistent local shopping bag; demo checkout; contact form validation; mobile navigation; FAQs.

Purchases, scheduling, and enquiry delivery are intentionally demo flows. No payment is taken, no appointment is booked, and no contact details are sent or stored. Connect real providers before launching. Replace sample prices, offers, biography, and stock photos with your actual details. Fonts and demo images are bundled locally, so the site does not need external asset requests. Font licenses are included under assets/. Demo images are sourced from the codewithsadee/fitlife template on GitHub; use your own photography before a public launch.
